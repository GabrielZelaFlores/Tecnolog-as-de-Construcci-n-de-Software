# Tecnologías de Construcción de Software

Proyecto académico: catálogo CRUD construido con Next.js, TypeScript y
arquitectura N-Capas. La aplicación usa Prisma/SQLite durante el desarrollo y
Netlify Blobs cuando se publica en Netlify.
